# Hi, I'm Lenny 👋

Mobile developer from Monterrey, México. I build native apps for **Android** with Kotlin and Jetpack Compose and for **iOS** with Swift and SwiftUI, from the first screen to the store release.

I care most about apps that keep working when things go wrong: offline-first data, honest error handling, and tests that catch real bugs.

## What I'm working on

- **Dishoo POS** — an Android tablet point of sale for coffee shops. It keeps selling without a network and syncs when it comes back, prints tickets on Bluetooth thermal printers, splits payments across cash, card and transfer, and runs several branches from one account. Kotlin, Jetpack Compose, Hilt, Room, Retrofit, Firebase.
- **OrderIt** — a tablet app for restaurant waiters and the Ktor API behind it.
